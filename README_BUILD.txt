FREELANCE ASSISTANT — ANDROID STUDIO PROJECT

This is an Android Studio project wrapper around the bilingual freelance-assistant MVP.

BUILD AN APK:
1. Install Android Studio on a computer.
2. Open this extracted project folder in Android Studio.
3. Allow Gradle sync to finish (internet connection required for Gradle/Android dependencies).
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location, normally:
   app/build/outputs/apk/debug/app-debug.apk

NOTES:
- This ZIP is Android Studio source code, not a precompiled APK.
- The app provides job-platform links, a proposal draft helper and a local application tracker.
- It does not autonomously log into freelance platforms, submit bids, perform paid work or receive money.
- Real platform automation requires approved APIs, secure backend services, and user-authorized connections.
- Never share OTPs/passwords or pay fees to unlock a job.
